# Политика безопасности

Не публикуйте сведения об уязвимости в GitHub Issues. Отправьте приватный
security advisory владельцу репозитория через вкладку **Security**.

Укажите затронутую версию, сценарий воспроизведения, влияние и предлагаемый
способ исправления. Не прикладывайте реальные токены, пароли, приватные записи
голоса или персональные данные.

Поддерживается последняя версия ветки `main`. Модели считаются данными:
удалённый код из модельных репозиториев не выполняется, production-ревизии
фиксируются commit SHA, а локальные файлы проверяются SHA-256.
