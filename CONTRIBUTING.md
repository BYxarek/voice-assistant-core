# Участие в разработке

## Локальная проверка

```powershell
cargo fmt --all -- --check
cargo clippy --workspace --all-targets --all-features -- -D warnings
cargo test --workspace --all-features
```

Изменение нетривиальной логики должно включать один минимальный тест,
воспроизводящий ожидаемое поведение. Не добавляйте аудиозаписи людей без их
явного согласия.

## Pull request

1. Создайте отдельную ветку.
2. Ограничьте изменение одной задачей.
3. Не коммитьте модели, логи, WAV-файлы или секреты.
4. Опишите способ ручной проверки аппаратно-зависимых изменений.
5. Убедитесь, что CI проходит на Windows.

Новые действия ассистента должны быть типизированными обработчиками. Передача
распознанного текста напрямую в shell запрещена.
